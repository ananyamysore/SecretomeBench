# Data sources and licensing

This repository includes no real papers, supplementary tables, or molecular datasets and makes no external-source verification claim. The synthetic fixtures are generated by this package and clearly labeled as such. Use user-provided evidence as the primary workflow. Public source access and redistribution terms must be checked directly; do not commit restricted full text or supplementary files. Record citation, DOI/PMID where verified, source URL, access/source date, license or access terms, extraction locator, checksum where applicable, and verification status.
